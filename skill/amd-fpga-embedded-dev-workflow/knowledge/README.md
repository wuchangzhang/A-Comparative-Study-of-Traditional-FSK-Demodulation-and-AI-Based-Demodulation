# Knowledge 索引

本目录仅由 S08 写入有证据来源的项目经验或已审查脚本。目录存在不表示已有经过验证的经验。

## 写入规则

- 经验文件使用英文小写路径：`entries/YYYY-MM-DD-short-title.md`。
- 脚本使用 `scripts/<name>`，并在同名 Markdown 文件中记录用途、依赖和验证状态。
- 每项必须记录 `validation_status`（`pending` 或 `verified`）、适用范围、失效条件和证据路径。
- `verified` 必须关联同一输入和问题的修复后验证；只有分析或建议时使用 `pending`。
- 不复制密钥、个人记忆、原始大日志或无法重新定位的截图。
