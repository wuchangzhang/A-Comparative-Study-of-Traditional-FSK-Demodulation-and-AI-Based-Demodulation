# EGO1 参考配置

## 参考项目配置

- 赛道：自主选题初级组，作品采用 RTL 实现，器件属于 AMD 7 Series。
- 工具：Vivado 2026.1，禁止自动切换其他发行版。
- 平台：EGO1 / Artix-7 XC7A35T；参考 Vivado part 为 `xc7a35tcsg324-1`，执行时须核对实际器件与工程。
- 参考系统时钟：100 MHz，需以板卡资料及当前 XDC 核对。
- 模拟链路：8 位 DAC0832 → LM324 → 物理 J2/DAC OUT。
- DAC 数据接口：执行前核对顶层至 DAC0832 的并行数据宽度确为 8 位；DDS 内部位宽可以更高，但量化/截位、符号和更新时序必须在 RTL 与验收计划中明确。
- 控制基线：五个普通按键，采用当前工程目录内经核对的 EGo1.xdc，不用其他板级描述覆盖实际引脚。

## 执行前必须填写

`project_path`、`top`、`sources`、`xdc`、复位极性与释放方式、板卡版本、引脚和连接器映射、工具安装路径、可用 MCP 工具名、采样率、频率范围及验收阈值。

这些值不得从文件名或历史工程猜测。FPGA 封装引脚名不等于排针位置；物理 J2 模拟输出不等于封装引脚 J2。

## 功能范围

基础：DDS 三波形、调频、数码管、DAC/J2；优先扩展：FSK。以当前已确认工程与任务为准，不覆盖已实现的第四波形、旋钮、拨码和上位机控制。

AD7606/AI 解调只在用户选定该扩展且提供对应工程与验收要求时启用，不因项目概览出现这些词就自动开发。外部 ADC 回环、传统/AI 两路以及 BER 证据分别记录。AI 未接入时明确不可用。

## 板级验收模板

- DAC：0x00/0x80/0xFF 静态码，记录实际电压、极性、削顶和负载，不预设对应电压。
- 波形：按已确认范围选择频点；早期参考为三波形 × 100/500/1000/2000 Hz，记录理论频率、实测频率、Vpp、误差与截图。
- FSK：核对实际帧/序列、两载频、码元周期、切频时刻和瞬态，不强制旧工程序列。
- 交互：短按、长按、边界、复位、模式切换，显示值应与已生效设置一致；显示值不是测量值。
- 测量：先确认共地、输出范围、示波器高阻与探头倍率；初始旁路可选滤波器，记录 DC/AC 耦合和采样设置。
- AD7606 扩展：记录模块模式、VIO、接线、采样率、丢样/削顶、同步、CRC 和 BER 的统计口径；数字内部回环不能替代外部模拟回环。

以上是待执行模板，不是本次测试结果。
