# S14 hw-debug

先读 [公共契约](../runtime-contract.md)。职责：使用真实 Vivado Hardware Manager/扩展能力对 ILA/VIO 进行发现、触发、采集和分析。

输入：`bitstream_manifest:string`、`debug_plan:string`、`hw_target:string`、`tool_adapter:object`、`debug_hub_manifest:string`。debug_plan 必须包含 probe、触发条件、采样深度、时钟、预期活动和导出格式。

前置：preflight 核对 bitstream/probes 哈希、debug hub/ILA/VIO 版本与时钟、目标器件身份、Hardware Server/target、授权动作和完整 debug_plan。缺失或不匹配返回 2；不得尝试连接、下载、触发或驱动 VIO。

流程：核对 bitstream 哈希、debug hub/ILA/VIO 版本、目标器件身份和时钟；发现核心后按计划配置 trigger，capture 并导出 CSV/VCD 或等价原始数据。VIO 驱动只执行明确授权的 probe，记录复位和写入值。将 ILA/VIO 数字活动与 DAC/J2/ADC 模拟测量分开，不能用内部波形替代示波器实测。

输出：`capture_paths:string[]`、`debug_findings:object[]`、`status:string`、`board_evidence:string`。

成功判据：每个捕获关联目标器件、bitstream 哈希、触发配置和原始文件；无硬件连接、debug core 不匹配或状态不明返回 2/6。默认异步 1800s，下载成功不等于功能验收通过。
