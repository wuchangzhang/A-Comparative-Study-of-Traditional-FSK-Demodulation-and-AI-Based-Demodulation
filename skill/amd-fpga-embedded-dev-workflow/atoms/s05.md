# S05 synth-impl

先读 [公共契约](../runtime-contract.md)。职责：在仿真准入通过后完成 RTL/HLS 产物的综合、实现，并按器件生成 bitstream 或 Versal PDI。

输入：`project_path:string`、`part:string`、`input_manifest:string`、`simulation_evidence:string`、`tool_adapter:object`、`acceptance_path:string`。可选 `hls_evidence:string`、`aie_evidence:string`、`image_type:string`（bitstream/pdi）。

前置：相关仿真或 HLS/AIE 准入退出码为 0，完整输入清单哈希一致；工具和平台符合项目声明；实际 top/part/XDC/平台与输入一致。无有效证据返回 2，禁止跳过检查。

流程：探测 MCP 对应能力，不可用再 batch；分别保存综合、实现、route、DRC、时钟/约束和 setup/hold 报告。核对已声明时钟、未约束路径、时序例外依据、资源使用与关键路径。禁止关闭 DRC 或添加无依据 false/multicycle path。只有实现和准入检查通过才生成最终交付 bitstream 或 PDI，检查返回值、文件存在性及组成清单。

输出：`bitstream_path:string|null`、`bitstream_manifest:string|null`、`pdi_paths:string[]`、`timing:object|null`、`utilization:object|null`、`report_paths:string[]`、`stage_results:object[]`。timing 包含 WNS/TNS/WHS/THS、setup/hold 失败端点数、未约束检查状态；未获得结果填 null。

最终验收采用最终交付 checkpoint 对应报告，记录 DCP 哈希及报告来源阶段；不混用中间 route 的裕量。准入同时记录 setup、hold、DRC、时钟和未约束检查，未解析项不得填 0。`no_input_delay` 等警告须逐端口/路径记录约束依据，不能按总数一概豁免。仅报告脚本兼容失败时，按 [受限续跑](../references/timing-recovery.md) 核对后新建 attempt；不得复用已知不支持的参数或删除检查来消除错误。

成功判据：实现完成、setup/hold 无失败、无阻断 DRC 和未解释的未约束关键路径、资源满足器件限制、bitstream/PDI 及哈希已归档。报告可由 S06 再解析，不替代本阶段准入。设计或约束失败返回 4。异步默认 7200s，公共契约适用。成功不代表已下载或模拟输出正常。
