# S08 asset-sink

先读 [公共契约](../runtime-contract.md)。职责：向本技能包 knowledge/ 写入可追溯经验或脚本。

输入：`entry:object` 或 `script:object`，至少一个；两者同时出现时分别产出并关联。entry 至少含 `title:string`、`trigger:string`、`observations:string[]`、`cause:string|null`、`resolution:string|null`、`evidence_paths:string[]`、`applicability:string[]`、`failure_conditions:string[]`、`validation_status:string`（pending/verified）。script 含 `name:string`、`content:string`、`usage:string`、`dependencies:string[]`、`evidence_paths:string[]`、`validation_status:string`。

流程：先读 [knowledge/README.md](../knowledge/README.md) 的命名和索引规则。核对来源、原失败与修复后回归是否对应同一问题；缺少运行证据时只能标 pending。verified 必须有有效验证证据，不接受模型自述作为效果证明。写入英文路径并更新知识索引，不覆盖原日志或已归档证据；不保存密钥，不写用户个人记忆。脚本写入不等于执行或验证。

输出：`written_path:string`、`additional_paths:string[]`、`validation_status:string`。

成功判据：写入内容有来源、状态准确、适用及失效边界清楚。默认 30s，公共契约适用。没有值得沉淀的观察时可跳过本 atom。
