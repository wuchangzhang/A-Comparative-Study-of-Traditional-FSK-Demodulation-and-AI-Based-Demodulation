# S06 report-read

先读 [公共契约](../runtime-contract.md)。职责：只读解析报告并给出有来源的验收判定。

输入：`report_paths:string[]`。可选 `acceptance_path:string`、`input_manifest:string`、`baseline_reports:string[]`、`report_kind:string`（rtl/hls/aie/timing/methodology）。

流程：核对报告生成阶段、part、top、平台、工具版本与输入来源。分别解析综合/实现资源和 routed timing，记录 WNS/TNS/WHS/THS、失败端点、约束/时钟、DRC、methodology、关键路径、LUT/FF/BRAM/URAM/DSP 使用及器件可用量；HLS 另记录 latency/II，AIE 另记录编译器/仿真产物。每项附报告路径和可定位位置，缺失填 null。优化比较必须说明是否同器件、版本、约束、测试条件，不把不同条件结果直接当优化收益。

输出：`timing:object`、`utilization:object`、`findings:object[]`、`acceptance:string`（pass/fail/unknown）、`comparison:object|null`。

成功判据：准确完成解析并列出未知项；成功解析失败报告可返回 0，但 acceptance=fail，不能放行 S09。默认 30s，公共契约适用；只读解析不启动 Vivado。
