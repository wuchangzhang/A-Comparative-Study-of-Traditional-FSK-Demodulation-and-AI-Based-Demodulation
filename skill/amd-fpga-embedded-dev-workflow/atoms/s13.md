# S13 aie-versal

先读 [公共契约](../runtime-contract.md)。职责：为 AMD Versal/AI Engine 设计定义边界并编排可验证的 AIE 编译、仿真、Vitis v++/平台打包和 PDI 证据。

输入：`platform:string`、`xsa:string`、`part:string`、`aie_sources:string[]`、`vitis_config:string`、`tool_adapter:object`、`tool_release:string`、`runtime_target:string`、`acceptance_path:string`。可选 `boot_pdi:string`、`pld_pdi:string`、`golden_reference:string`。

前置：preflight 核对 Versal part、platform/XSA、AIE/PL/PS 边界、source/kernel、Vitis/Vitis AI 版本、运行时目标、配置、测试/参考和验收阈值。平台、NoC、DDR、PS 或 AIE 硬件事实先通过 Vivado AI MCP 查询；查询不到时请求用户提供对应原始资料并返回 2，不启动作业。

流程：先确认 Versal 器件、AIE/PL/PS 边界、Vitis/Vitis AI 版本和运行时目标。AIE kernel 的编译优化以实际编译器报告、生成的 assembly/map/calltree 或仿真结果为依据；不要把 Peano/AIE 建议当作已验证 QoR。使用 Segmented Configuration 时分别记录 boot.pdi 与 pld.pdi、NoC/DDR 初始启动路径、SEGCONFIG/pr_verify 结果。模型量化、NPU 推理和板级吞吐属于外部证据链。

输出：`aie_evidence:string`、`pdi_manifest:string|null`、`reports:string[]`、`open_items:object[]`。

成功判据：平台、编译器、目标 part 和每个产物哈希可追溯；缺少 Versal/AIE 工具或运行时只返回阻塞，不降级为 EGO1 结论。默认异步 7200s，公共退出码适用。
