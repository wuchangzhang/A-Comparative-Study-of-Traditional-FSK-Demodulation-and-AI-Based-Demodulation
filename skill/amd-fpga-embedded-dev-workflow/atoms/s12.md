# S12 hls-accelerator

先读 [公共契约](../runtime-contract.md)。职责：管理 Vitis HLS 组件的 csim、csynth、C/RTL cosim 和 impl 证据，并给出可追溯 QoR。

输入：`hls_component:string`、`hls_config:string`、`acceptance_path:string`、`tool_adapter:object`、`tool_release:string`、`top_function:string`、`part:string`、`clock_ns:number`、`testbench:string`、`golden_reference:string`。需要平台集成时另需 `platform:string` 或 `xsa:string`。

前置：preflight 核对工具版本、component、top function、源文件/头文件、接口、part/平台、时钟、testbench、golden reference 和验收阈值；缺失即返回 2，不启动 HLS 作业。

流程：核对 top function、源文件、头文件、接口（AXI/stream/ap_fifo）、part 和时钟；先检查可综合性与 C 仿真，再按配置运行 csynth、cosim、impl。记录 latency、II、时钟、LUT/FF/BRAM/URAM/DSP、接口协议和失败日志。dataflow、pipeline、array-to-stream、burst 等优化只在报告支持时提出，修改需另走 S03 或明确的 HLS 代码授权。

输出：`hls_evidence:string`、`reports:string[]`、`status:string`、`qor:object`、`open_items:object[]`。

成功判据：每个阶段状态与输入配置绑定；cosim 失败不能被 csynth PASS 覆盖，QoR 不能直接当作板级性能。工具或许可证不可确认返回 3，设计/测试失败返回 4，异步默认 7200s。
