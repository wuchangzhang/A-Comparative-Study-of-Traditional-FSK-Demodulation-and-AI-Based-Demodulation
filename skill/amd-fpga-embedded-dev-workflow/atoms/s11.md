# S11 rtl-quality

先读 [公共契约](../runtime-contract.md)。职责：在综合前分析真实 RTL 的 lint、elaboration 和 Vivado timing methodology 结果，不代替完整综合/实现。

输入：`project_or_sources:string`、`tool_adapter:object`。可选 `lint_report:string`、`synthesis_log:string`、`methodology_report:string`、`part:string`、`top:string`。

流程：确认 project/non-project 模式、top、part、编译顺序和工具版本；优先使用 AMD 扩展对应的 Vivado 操作，或同版本工具。lint 报告必须使用该版本的结构化输出；不得凭截图或手工猜测违规项。elaboration 逐条关联真实日志和 RTL 行号；timing methodology 按 UG906/实际检查 ID 分类，区分工具警告、约束问题和 RTL 问题。

输出：`quality_report:string`、`findings:object[]`、`repair_target:string`（S01/S03/none）、`invalidated_evidence:string[]`。

成功判据：所有发现都有原始报告位置、严重度和下一步；没有报告或无法确认工具/设计上下文返回 2/3。该 atom 不自动改码、不放宽 waiver、不宣称时序收敛。默认 180s，公共退出码适用。
