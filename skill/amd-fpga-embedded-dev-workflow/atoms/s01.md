# S01 project-init

先读 [公共契约](../runtime-contract.md)。职责：在显式输出路径创建或复用工程，不重写原始源码。

输入：`mode:string`（create/reuse）、`part:string`、`top:string`、`xdc:string`、`sources:string[]`、`tool_adapter:object`、`approved_plan:string`。可选 `project_path:string`（reuse 时必填）、`defines:string[]`、`include_dirs:string[]`、`parameters:object`、`init_files:string[]`、`ip_files:string[]`、`block_designs:string[]`、`hls_components:string[]`、`aie_platform:string`、`build_scripts:string[]`。

前置：详细方案须已由用户确认。preflight 核对 mode、工程路径、完整 part、top、源文件清单、XDC/平台文件、时钟复位、工具版本和本次验收范围；缺一项即返回 2，不创建或修改工程。

流程：核对全部文件与顶层端口，检查完整 part、源文件编译顺序、ROM/IP/HLS/AIE 路径、时钟复位、XDC pin-to-port 和已知管脚归属；在 DAC/ADC 等外设边界核对 HDL 数据位宽、符号、更新使能与器件接口宽度。引脚、平台、连接器或外设事实先按入口的硬件资料查询规则取证；MCP 无资料时请求用户提供原始资料，不联网补找。需调用 Vivado/Vitis 时先确认项目声明版本。create 不覆盖已有工程；reuse 保存原工程配置快照后仅修改声明的工程配置。未提供可靠引脚、平台或器件依据时返回 2，不猜测，不执行综合。

输出：`project_path:string`、`files:string[]`、`input_manifest:string`、`configuration_diff:string|null`。

成功判据：工程配置与输入清单一致、依赖完整、变更可追溯。默认 120s，公共退出码适用。创建工程不代表仿真或实现通过。
