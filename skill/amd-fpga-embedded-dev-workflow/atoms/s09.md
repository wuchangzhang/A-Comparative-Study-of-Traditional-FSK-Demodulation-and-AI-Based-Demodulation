# S09 board-verify

先读 [公共契约](../runtime-contract.md)。职责：按已授权的测试计划执行下载和板级验证，或输出明确阻塞项。

输入：`bitstream_manifest:string`、`board_profile:string`、`schematic:string`、`pin_mapping:string`、`wiring_plan:string`、`test_plan:string`、`implementation_evidence:string`、`tool_adapter:object`。test_plan 明确硬件目标、接线、仪器、量程/负载、期望结果和允许的动作。自动测量仅在存在真实可用适配器时执行。

前置：核对当前 bitstream 哈希、S04/S05 来源绑定、实现时序和 DRC 准入、实际板卡/revision、适用原理图、当前 XDC/pin mapping、连接器映射、电平与信号范围、接线、仪器和测量设置。硬件资料先由 Vivado AI MCP 查询；MCP 不可用或无资料时请求用户提供。任一项未确认即返回 2，附缺失项、问题和恢复条件；不得创建作业、连接或下载硬件。已明确授权的例行操作无需重复批准，但不得超出任务范围。

流程：确认项目声明版本，枚举并记录目标器件身份，不自动选取未知板卡；下载后保留状态日志。随后分别记录数字 IO、ILA/VIO 计划内观测、DAC 静态码、J2 动态波形、交互、FSK 或 AIE/加速器测试。外部 ADC/AI 分支只按本次范围执行。人工测量数据注明提供方式、时间和测试条件；不把人工记录冒充自动采集。

输出：`programming:object`、`measurements:object[]`、`board_evidence:string`、`blocked_items:object[]`。每项测量记录 check_id、参考值、实测值、单位、容差、条件、原始数据/截图、bitstream 哈希和结果。

成功判据：本次全部必选测试有实际证据且通过。只有下载成功时，programming 可为 pass，其他测试仍为 not_run；不能返回整套验收成功。已获得测量的设计失败可返回 4，缺设备/输入返回 2。异步默认 1800s，公共契约适用。禁止推测输出电压、接线位置或 BER。
